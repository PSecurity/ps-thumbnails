### // FUNÇÕES_DISPONÍVEIS
 * **Edição em Tempo Real:** Altere títulos e comandos do terminal instantaneamente.

### // COMO_OPERAR
 1. Execute o index.html em qualquer navegador moderno.
 2. No painel **sudo ps.editor**, configure os vetores de texto.
 3. Insira a URL de um asset transparente (Máscara/Logo).
 4. Clique no botão de compilação para gerar o arquivo .png.
